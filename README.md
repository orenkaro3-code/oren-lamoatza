# אורן למועצה

אתר הקמפיין, תיבת הרעיונות, ספירת "אני מצביע לאורן" ופאנל אדמין. שלט המצגת נמצא בפרויקט נפרד (oren-remote).

## מה יש בפרויקט

| כתובת | מה זה |
|---|---|
| `/` | אתר הקמפיין לתלמידים |
| `/api/...` | השרת הקטן ששומר רעיונות וקולות |

## העלאה ל-Vercel (פעם אחת, בערך 10 דקות)

1. פותחים ריפו חדש ב-GitHub ומעלים אליו את **התוכן** של התיקייה הזאת (`public`, `api`, `lib`, `package.json`, `vercel.json`) ישר בשורש הריפו. אם העליתם את התיקייה עצמה, כוונו ב-Vercel את **Root Directory** ל-`oren-site`.
2. ב-Vercel: **Add New → Project**, בוחרים את הריפו ולוחצים **Deploy**. לא צריך לשנות שום הגדרה.
3. מוסיפים מאגר נתונים: בפרויקט ב-Vercel נכנסים ל-**Storage**, לוחצים **Create Database**, בוחרים **Upstash for Redis** (יש חינמי) ומחברים אותו לפרויקט.
4. **Deployments → ⋯ → Redeploy**, כדי שהמאגר ייכנס לתוקף.

## פאנל האדמין

באתר לוחצים **5 פעמים מהר** על המילה הגדולה "אורן" בראש הדף.
בפעם הראשונה בוחרים סיסמה (לפחות 6 תווים). מהפעם השנייה מקלידים אותה.
רואים כמה אנשים לחצו "אני מצביע לאורן", ואת כל הרעיונות לפי נושא, עם אפשרות למחוק.
בלי הסיסמה הפאנל לא מראה כלום, גם למי שמגלה את הטריק של 5 הלחיצות.

## הערות

- הספירה של "אני מצביע לאורן" נספרת פעם אחת לכל דפדפן. זה כפתור תמיכה, לא הצבעה רשמית.
- אם משהו לא עובד, פותחים את פאנל האדמין: הוא כותב בדיוק מה חסר (מאגר, סיסמה או קבצים).
